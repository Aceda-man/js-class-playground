## Challenges

1. Write an arrow function called `reverseString` that takes a string as input. It should return the string reversed.

2. Write an arrow function called `isPrime` that takes a number as input. It should return `true` if the number is prime, and `false` otherwise.

3. Write arrow functions called `add`, `subtract`, `multiply`, and `divide`, each taking two numbers as inputs. Each should return the result of that operation.

4. Write an arrow function called `celsiusToFahrenheit` that takes a temperature in Celsius as input. It should calculate and return the temperature in Fahrenheit using the formula: (celsius * 9/5) + 32.

5. Write an arrow function called `isPalindrome` that takes a string as input. It should return whether the string reads the same forwards and backwards.

6. Write an arrow function called `countVowels` that takes a string as input. It should return the number of vowels (a, e, i, o, u) in the string.

7. Write an arrow function called `findLargest` that takes an array of numbers as input. It should return the largest number in the array.

8. Write an arrow function called `fizzBuzz` that takes no inputs. It should print the numbers 1 to 100, but print "Fizz" for multiples of 3, "Buzz" for multiples of 5, and "FizzBuzz" for multiples of both.

9. Write an arrow function called `sumArray` that takes an array of numbers as input. It should return the sum of all the numbers.

10. Write an arrow function called `hasUniqueChars` that takes a string as input. It should return whether all characters in the string are unique (no repeats).

11. Write an arrow function called `calculateBMI` that takes weight (in kg) and height (in metres) as inputs. It should calculate BMI using the formula: weight divided by (height * height). It should return whether the result is Underweight (below 18.5), Normal (18.5 to 24.9) or Overweight (25 and above).
